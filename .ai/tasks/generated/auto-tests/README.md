# AI Generated Auto-Tests

Playwright specs in this folder are executed by:

- **CI:** `.github/workflows/ai-generated-tests.yml`
- **Config:** `playwright.ai-generated.config.ts` (not `playwright.config.ts`)
- **Local:** `npm run test:ai-generated`

Place generated `*.spec.ts` files here after review/promotion from `.ai/tasks/review/auto-tests`.
