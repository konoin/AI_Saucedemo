# Feature Analysis Request

## Feature Name

Checkout Process

## Application

SauceDemo

## Business Goal

Verify that a user can successfully complete a purchase.

## Scope

### Must test

- Login with valid user
- Add product to cart
- Open cart
- Checkout
- Complete order

### Negative scenarios

- Empty checkout form
- Missing first name
- Missing last name
- Missing postal code

### Out of scope

- Performance testing
- Accessibility testing
- API testing

## Risks

- Order completion failure
- Cart data loss
- Validation errors

## Additional Notes

Generate complete test cases covering positive and negative scenarios.
Each test case must be created as a separate markdown file.
