## Name MP-01 - Login with valid credentials

## Priority
High

## Type
Positive

## Steps

1. 1. Open the SauceDemo application (https://www.saucedemo.com).
2. 2. Verify the login page is displayed.
3. 3. Enter a valid username (e.g., standard_user) into the username field.
4. 4. Enter the valid password (e.g., secret_sauce) into the password field.
5. 5. Click the Login button.

## Expected Result

User is redirected to the inventory page (/inventory.html). Inventory page elements (product list, header, cart) are visible. No error message is displayed.
