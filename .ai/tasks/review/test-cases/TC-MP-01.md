# MP-01 - Successful checkout with single product

## Priority
High

## Type
Positive

## Steps

1. Open SauceDemo application.
2. Login with valid credentials (username: standard_user, password: secret_sauce).
3. Verify landing on products page.
4. Select one product (e.g., Sauce Labs Backpack) and click 'Add to cart'.
5. Click the cart icon to open the cart page.
6. Verify the selected product is listed in the cart with correct name and price.
7. Click 'Checkout'.
8. On Checkout: Your Information page, enter valid First Name, Last Name, Postal Code (e.g., John, Doe, 12345).
9. Click 'Continue'.
10. Verify the Checkout: Overview page displays the correct item, item total, tax and total.
11. Click 'Finish' to complete the order.

## Expected Result

User completes checkout successfully and is navigated to the order confirmation page which displays a confirmation message (e.g., 'THANK YOU FOR YOUR ORDER') and order summary. Cart is emptied for the user after completion.
