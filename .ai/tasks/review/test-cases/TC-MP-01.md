## Name MP-01 - Login with valid credentials

## Priority
High

## Type
Positive

## Steps

1. 1. Open the SauceDemo application and navigate to the login page.
2. 2. Enter a valid username (e.g., standard_user) into the Username field.
3. 3. Enter a valid password (e.g., secret_sauce) into the Password field.
4. 4. Click the Login button.

## Expected Result

User is authenticated and redirected to the inventory page (/inventory.html). Product list is visible and no error messages are shown.
