# MP-01 - Successful checkout with single product

## Priority
High

## Type
Positive

## Steps

1. Precondition: Browser is open and clear of previous session data.
2. 1. Navigate to SauceDemo (https://www.saucedemo.com).
3. 2. Log in using valid credentials: username = 'standard_user', password = 'secret_sauce'.
4. 3. On the products page, locate 'Sauce Labs Backpack' and click 'Add to cart'.
5. 4. Click the cart icon to open the cart page.
6. 5. Verify the product is listed in the cart and click 'Checkout'.
7. 6. On the 'Checkout: Your Information' page, enter First Name = 'John', Last Name = 'Doe', Postal Code = '90210'.
8. 7. Click 'Continue' to go to the overview page.
9. 8. On the 'Checkout: Overview' page, verify item, price and total, then click 'Finish'.
10. 9. Verify the application navigates to the order confirmation page.

## Expected Result

User completes checkout successfully. The order confirmation page is displayed with confirmation text (e.g., 'THANK YOU FOR YOUR ORDER' or equivalent). Cart is emptied (no items in cart badge).
