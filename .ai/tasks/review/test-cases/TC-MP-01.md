## Name MP-01 - Login with valid credentials

## Priority
High

## Type
Positive

## Steps

1. Open the SauceDemo application in a supported browser (https://www.saucedemo.com).
2. Verify the login page is displayed with Username and Password fields and Login button.
3. Enter a valid username (e.g., standard_user) in the Username field.
4. Enter the corresponding valid password (e.g., secret_sauce) in the Password field.
5. Click the Login button.

## Expected Result

User is successfully authenticated and redirected to the Inventory page (URL contains /inventory.html). Inventory items are visible and the application menu is available.
