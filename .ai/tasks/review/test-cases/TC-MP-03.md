## Name MP-03 - Session persistence after browser refresh

## Priority
High

## Type
Positive

## Steps

1. Precondition: User is logged in and is on the Inventory page (use MP-01).
2. 1. Click the browser Refresh/Reload button (or press F5).
3. 2. Observe the page and session state.

## Expected Result

After refresh the user remains authenticated and on the Inventory page. No re-login prompt is shown and inventory data loads normally.
