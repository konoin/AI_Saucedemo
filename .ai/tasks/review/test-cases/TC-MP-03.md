## Name MP-03 - Access inventory page after login

## Priority
High

## Type
Positive

## Steps

1. Log in with valid credentials (standard_user / secret_sauce).
2. From the Inventory page, verify elements that confirm access (product list, product names, prices).
3. Manually navigate (or refresh) to /inventory.html and verify the page remains accessible while logged in.

## Expected Result

Authenticated user can access the Inventory page and view product listings. URL /inventory.html loads successfully and displays products.
