## Name MP-03 - Session persistence after browser refresh

## Priority
Medium

## Type
Positive

## Steps

1. Log in using valid credentials (standard_user / secret_sauce)
2. On the inventory page, refresh the browser (F5 / reload)
3. Observe the page and UI elements after refresh
4. Optionally, repeat refresh multiple times

## Expected Result

After refresh the user remains authenticated, inventory items remain visible, and no login page is shown. Session token/cookie remains valid and UI remains consistent.
