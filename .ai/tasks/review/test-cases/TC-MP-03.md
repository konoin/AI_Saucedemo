## Name MP-03 - Session persistence after browser refresh

## Priority
Medium

## Type
Positive

## Steps

1. 1. Login using valid credentials (Username: standard_user, Password: secret_sauce)
2. 2. Verify you are on the inventory page
3. 3. Click the browser refresh/reload button (F5 or browser refresh)
4. 4. Observe the current page and session state

## Expected Result

After refresh the user remains authenticated and stays on the inventory page. No forced redirect to the login page occurs and inventory content remains visible.
