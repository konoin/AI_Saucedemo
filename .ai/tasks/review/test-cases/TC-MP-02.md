## Name MP-02 - Logout after successful login

## Priority
High

## Type
Positive

## Steps

1. 1. Login using valid credentials (Username: standard_user, Password: secret_sauce)
2. 2. Verify you are on the inventory page
3. 3. Click the menu (hamburger) icon
4. 4. Click the Logout option
5. 5. Observe the application behavior

## Expected Result

User is logged out and redirected to the login page. Inventory page requires re-authentication and protected content is no longer accessible without logging in.
