Name MP-02 - Successful checkout with multiple products

## Priority

High

## Type

Positive

## Steps

1. Open SauceDemo and log in with username 'standard_user' and password 'secret_sauce'.
2. On products page, add two different products (e.g., 'Sauce Labs Backpack' and 'Sauce Labs Bike Light') to the cart.
3. Verify the cart badge shows '2'.
4. Open the cart page and verify both products are present with correct names and prices.
5. Click 'Checkout'.
6. Enter valid checkout information: First name 'Alice', Last name 'Smith', Postal Code '90210' and click 'Continue'.
7. On Overview, verify both items are present with correct quantities and the order totals reflect both items.
8. Click 'Finish'.

## Expected Result

Order completes successfully with both items included. Confirmation page is shown and totals correspond to the items purchased.
