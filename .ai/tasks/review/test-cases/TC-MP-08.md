## Name MP-08 - Login attempt with invalid username

## Priority
High

## Type
Negative

## Steps

1. 1. Navigate to https://www.saucedemo.com/
2. 2. In Username field enter: invalid_user
3. 3. In Password field enter: secret_sauce
4. 4. Click Login.

## Expected Result

Login fails. The application displays the error message: "Epic sadface: Username and password do not match any user in this service" (or equivalent). No inventory access.
