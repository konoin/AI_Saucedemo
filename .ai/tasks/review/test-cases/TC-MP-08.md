## Name MP-08 - Login attempt with invalid username

## Priority
High

## Type
Negative

## Steps

1. 1. Open https://www.saucedemo.com/
2. 2. Enter Username: invalid_user
3. 3. Enter Password: secret_sauce
4. 4. Click the Login button

## Expected Result

Login fails. An error message is shown indicating username and password do not match any user (e.g., 'Epic sadface: Username and password do not match any user in this service'). User remains on the login page.
