## Name MP-08 - Login attempt with empty username and password

## Priority
High

## Type
Negative

## Steps

1. Open the SauceDemo login page.
2. Leave both Username and Password fields empty.
3. Click Login.

## Expected Result

Login fails. An appropriate error message is shown (e.g., 'Epic sadface: Username is required' or combined message). User remains on the login page and cannot authenticate.
