## Name MP-08 - Login attempt with empty username and password

## Priority
Medium

## Type
Negative

## Steps

1. 1. Navigate to the login page.
2. 2. Leave both Username and Password fields empty.
3. 3. Click the Login button.

## Expected Result

Login is rejected. An informative error message is displayed (e.g., 'Epic sadface: Username is required' or combined validation). No authentication occurs and the user remains on the login page.
