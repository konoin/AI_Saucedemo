## Name MP-08 - Login attempt with empty username and password

## Priority
High

## Type
Negative

## Steps

1. 1. Open the login page.
2. 2. Leave both username and password fields empty.
3. 3. Click Login.

## Expected Result

Login is blocked. Displayed error message indicates a required field (commonly "Epic sadface: Username is required"). User remains on the login page and is not authenticated.
