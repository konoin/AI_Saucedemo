## Name MP-09 - Login attempt with invalid password

## Priority
High

## Type
Negative

## Steps

1. 1. Open https://www.saucedemo.com/
2. 2. Enter Username: standard_user
3. 3. Enter Password: wrong_password
4. 4. Click the Login button

## Expected Result

Login fails. An error message is shown indicating username and password do not match any user. User remains on the login page.
