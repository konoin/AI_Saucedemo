## Name MP-09 - Login attempt with invalid password

## Priority
High

## Type
Negative

## Steps

1. Open the SauceDemo login page
2. Enter username: standard_user
3. Enter password: wrong_password
4. Click the Login button

## Expected Result

Login is rejected and an authentication failure message is shown (e.g., 'Epic sadface: Username and password do not match any user in this service'). User remains on the login page.
