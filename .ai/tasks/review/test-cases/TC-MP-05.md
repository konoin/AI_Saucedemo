## Name MP-05 - Login attempt with empty username

## Priority
High

## Type
Negative

## Steps

1. 1. Navigate to https://www.saucedemo.com/
2. 2. Leave Username field empty.
3. 3. In the Password field enter: secret_sauce
4. 4. Click Login.

## Expected Result

Login fails. The application displays the error message: "Epic sadface: Username is required" (or equivalent). No access to inventory page is granted.
