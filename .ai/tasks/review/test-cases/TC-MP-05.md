## Name MP-05 - Login attempt with empty username

## Priority
High

## Type
Negative

## Steps

1. Open the SauceDemo login page
2. Leave the Username field empty
3. Enter a valid password (secret_sauce)
4. Click the Login button

## Expected Result

Login is rejected and an error message is displayed indicating the username is required (e.g., 'Epic sadface: Username is required'). User remains on the login page.
