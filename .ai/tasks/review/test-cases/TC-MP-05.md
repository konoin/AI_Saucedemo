## Name MP-05 - Access inventory page after login by direct navigation

## Priority
High

## Type
Positive

## Steps

1. 1. Login successfully (standard_user / secret_sauce).
2. 2. In the address bar, navigate directly to /inventory.html (or click a direct inventory link).
3. 3. Verify the page loads.

## Expected Result

The inventory page loads successfully and user remains authenticated. Page elements load and function normally.
