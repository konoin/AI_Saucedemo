## Name MP-05 - Session persistence after page refresh

## Priority
Medium

## Type
Positive

## Steps

1. Log in with valid credentials and land on the Inventory page.
2. Refresh the browser (F5 or browser refresh).
3. Observe the application state after refresh.

## Expected Result

User remains authenticated after refresh and stays on the Inventory page (products still visible). No forced logout occurs solely due to refresh.
