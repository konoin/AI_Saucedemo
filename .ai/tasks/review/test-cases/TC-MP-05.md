## Name

MP-05 - Checkout attempt with missing last name

## Priority

High

## Type

Negative

## Steps

1. Log in with valid credentials.
2. Add a product to the cart and open the cart page.
3. Click 'Checkout' to navigate to the information page.
4. Enter First name: 'Emma' and Postal Code: '30303' but leave Last name blank. Click 'Continue'.

## Expected Result

Checkout is blocked and a validation error message is shown indicating the last name is required (e.g., 'Error: Last Name is required' or equivalent). The user must supply Last name to proceed.
