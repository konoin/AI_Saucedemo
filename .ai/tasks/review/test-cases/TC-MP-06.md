## Name MP-06 - Login attempt with empty username

## Priority
Medium

## Type
Negative

## Steps

1. 1. Navigate to the login page.
2. 2. Leave the Username field empty.
3. 3. Enter a valid password (secret_sauce) into the Password field.
4. 4. Click the Login button.

## Expected Result

Login is rejected. An informative error message is displayed indicating the username is required (e.g., 'Epic sadface: Username is required') and the user remains on the login page.
