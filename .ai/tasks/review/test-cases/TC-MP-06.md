## Name MP-06 - Login attempt with empty password

## Priority
High

## Type
Negative

## Steps

1. Open the SauceDemo login page
2. Enter a valid username (standard_user)
3. Leave the Password field empty
4. Click the Login button

## Expected Result

Login is rejected and an error message is displayed indicating the password is required (e.g., 'Epic sadface: Password is required'). User remains on the login page.
