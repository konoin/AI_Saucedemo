## Name MP-06 - Login attempt with empty password

## Priority
High

## Type
Negative

## Steps

1. 1. Navigate to https://www.saucedemo.com/
2. 2. In Username field enter: standard_user
3. 3. Leave Password field empty.
4. 4. Click Login.

## Expected Result

Login fails. The application displays the error message: "Epic sadface: Password is required" (or equivalent). No access to inventory page is granted.
