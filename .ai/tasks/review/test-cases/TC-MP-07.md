## Name MP-07 - Login attempt with empty username and password

## Priority
High

## Type
Negative

## Steps

1. 1. Navigate to https://www.saucedemo.com/
2. 2. Leave both Username and Password fields empty.
3. 3. Click Login.

## Expected Result

Login fails. The application displays an appropriate error message (commonly "Epic sadface: Username is required"). No access to inventory page is granted.
