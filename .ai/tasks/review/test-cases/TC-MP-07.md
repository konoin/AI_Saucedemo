## Name MP-07 - Login attempt with empty username and password

## Priority
High

## Type
Negative

## Steps

1. Open the SauceDemo login page
2. Leave both Username and Password fields empty
3. Click the Login button

## Expected Result

Login is rejected and an error message is displayed indicating missing credentials (commonly 'Epic sadface: Username is required' or a message specifying both fields). User remains on the login page.
