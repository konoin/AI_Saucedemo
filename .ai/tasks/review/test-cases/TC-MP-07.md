## Name MP-07 - Login fail with empty username and password

## Priority
High

## Type
Negative

## Steps

1. Precondition: Browser on SauceDemo login page.
2. Step 1: Leave both username and password fields blank.
3. Step 2: Click 'Login'.

## Expected Result

Login is rejected. Appropriate error message(s) indicating missing credentials are displayed. No session is created and user remains on login page.
