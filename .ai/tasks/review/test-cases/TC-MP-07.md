## Name MP-07 - Login attempt with empty password

## Priority
Medium

## Type
Negative

## Steps

1. 1. Navigate to the login page.
2. 2. Enter a valid username (standard_user) into the Username field.
3. 3. Leave the Password field empty.
4. 4. Click the Login button.

## Expected Result

Login is rejected. An informative error message is displayed indicating the password is required (e.g., 'Epic sadface: Password is required') and no authenticated session is created.
