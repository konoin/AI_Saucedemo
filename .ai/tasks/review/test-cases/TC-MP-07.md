## Name MP-07 - Login attempt with empty password

## Priority
High

## Type
Negative

## Steps

1. 1. Open the login page.
2. 2. Enter a valid username (standard_user).
3. 3. Leave the password field empty.
4. 4. Click Login.

## Expected Result

Login is blocked. Displayed error message: "Epic sadface: Password is required" (or equivalent required-password error). User remains on the login page and is not authenticated.
