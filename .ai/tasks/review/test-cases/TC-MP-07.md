## Name MP-07 - Login attempt with empty username and password

## Priority
High

## Type
Negative

## Steps

1. 1. Open https://www.saucedemo.com/
2. 2. Leave both Username and Password fields empty
3. 3. Click the Login button

## Expected Result

Login is blocked. An error message is shown indicating username is required (the application should not proceed). User remains on the login page.
