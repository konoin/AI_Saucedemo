## Name MP-12 - Locked user login attempt (locked_out_user)

## Priority
High

## Type
Negative

## Steps

1. 1. Navigate to the login page.
2. 2. Enter Username = locked_out_user.
3. 3. Enter Password = secret_sauce.
4. 4. Click the Login button.

## Expected Result

Login is rejected. The application displays a locked-out error message (e.g., 'Epic sadface: Sorry, this user has been locked out.'). The user cannot access the inventory page.
