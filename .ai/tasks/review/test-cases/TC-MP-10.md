## Name MP-10 - Login attempt with invalid password

## Priority
Medium

## Type
Negative

## Steps

1. 1. Navigate to the login page.
2. 2. Enter a valid username (standard_user) into the Username field.
3. 3. Enter an incorrect password (e.g., wrong_password) into the Password field.
4. 4. Click the Login button.

## Expected Result

Login is rejected and an error message is shown indicating credentials are invalid (e.g., 'Epic sadface: Username and password do not match any user in this service').
