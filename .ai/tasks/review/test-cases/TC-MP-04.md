## Name MP-04 - Access inventory page immediately after login

## Priority
High

## Type
Positive

## Steps

1. Open the SauceDemo login page
2. Log in using valid credentials (standard_user / secret_sauce)
3. Verify that the application navigates to /inventory.html
4. Confirm inventory page content is accessible (product list, add-to-cart buttons)

## Expected Result

Inventory page is accessible and functions as expected (products displayed, interaction possible). No additional authentication prompts appear.
