## Name MP-04 - Session persistence after browser refresh

## Priority
High

## Type
Positive

## Steps

1. 1. Login successfully (standard_user / secret_sauce).
2. 2. When on the inventory page, refresh the browser (F5 / reload).
3. 3. Observe page state and confirm user remains logged in.

## Expected Result

After refresh, the user remains on the inventory page and stays authenticated. Inventory content remains visible and user can continue interacting without re-login.
