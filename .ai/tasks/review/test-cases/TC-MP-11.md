## Name MP-11 - Login attempt with invalid username and password

## Priority
Medium

## Type
Negative

## Steps

1. 1. Open the login page.
2. 2. Enter an invalid username (invalid_user).
3. 3. Enter an invalid password (wrong_password).
4. 4. Click Login.

## Expected Result

Login fails. Displayed error message: "Epic sadface: Username and password do not match any user in this service". User remains on the login page.
