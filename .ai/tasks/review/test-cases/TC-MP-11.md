## Name MP-11 - Locked user login attempt (locked_out_user)

## Priority
High

## Type
Negative

## Steps

1. 1. Navigate to https://www.saucedemo.com/
2. 2. In Username field enter: locked_out_user
3. 3. In Password field enter: secret_sauce
4. 4. Click Login.

## Expected Result

Login fails. The application displays the locked-out error message: "Epic sadface: Sorry, this user has been locked out." (or equivalent). No inventory access.
