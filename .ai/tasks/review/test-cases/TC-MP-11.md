## Name MP-11 - Login attempt with invalid username and password

## Priority
High

## Type
Negative

## Steps

1. Open the SauceDemo login page.
2. Enter invalid username and invalid password (e.g., userX / passY).
3. Click Login.

## Expected Result

Login fails. Error message indicates credentials are invalid (e.g., 'Epic sadface: Username and password do not match any user in this service'). No session is created.
