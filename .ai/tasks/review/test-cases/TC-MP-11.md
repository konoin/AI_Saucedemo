## Name MP-11 - Locked user login attempt (locked_out_user)

## Priority
High

## Type
Negative

## Steps

1. Open the SauceDemo login page
2. Enter username: locked_out_user
3. Enter password: secret_sauce
4. Click the Login button

## Expected Result

Login is rejected and a locked account message is displayed (e.g., 'Epic sadface: Sorry, this user has been locked out.'). User remains on the login page and cannot proceed to inventory.
